# Upstream UI primitives

This is the **headless** tier. It imports maintained React packages for behavior and accessibility. Those packages ship almost no CSS, so the Default stories look like bare browser controls. That is the upstream default, not a missing theme.

The **Themed** stories apply Academy hover `#0035B1` and press `#DEF54F` through `className` and CSS variables. That CSS is local agent styling. It is not an upstream design language.

Compare finished design languages in **Styled systems**. This section does not recreate package mechanics and does not promote a candidate to production.

## Omitted candidates

| Candidate | Reason |
| --- | --- |
| shadcn copy-paste | Official Base UI docs treat shadcn as a pre-styled Base UI layer. Importing Base UI avoids copied wrappers. |
| `input-otp` | Base UI 1.8.0 includes OTP Field. Extra package would duplicate that primitive. |
| Radix Accordion / Progress | Issue 194 recorded them as maintained but not required once Base UI is present. |
| React Aria | Evaluated alternative. Base UI already supplies the selected primitives. |
