# Runtime additions

`motion` 13.2.0 stays the default. An extra package appears here only when Motion cannot produce the effect. Issue 194 still rejects GSAP, React Spring, and `@formkit/auto-animate` where the effect is the same as Motion.

Every row names the component that needs the package and the reason. A component that adds a runtime without a row here fails the rubric in issue 268.

| `react-use-measure` | 2.1.7 | MIT | 29 KB | Sliding number | SlidingNumber measures each digit height so the reel can translate in pixels. Motion springs the digit. It does not measure the glyph box. https://github.com/pmndrs/react-use-measure |
