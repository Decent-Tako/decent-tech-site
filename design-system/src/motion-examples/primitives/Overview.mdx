| Sliding number | Each digit is a 0-9 reel. `useSpring` advances a `motionValue`. `useTransform` offsets Y by the measured glyph height. | `react-use-measure` 2.1.7 |
| Morphing dialog | Shared `layoutId` between the card trigger and a portaled dialog. `AnimatePresence` fades the backdrop. | none |
| Image comparison | A motion value at 50 percent. `useSpring` moves the handle. `useTransform` sets left and right `clipPath`. | none |
| Text shimmer | `useMemo` sets `--spread`. A `motion` element animates `backgroundPosition` with `background-clip: text`. | none |
| Text shimmer wave | Each character is a `motion.span`. Keyframes run translate, scale, rotateY, and colour. | none |
| Spinning text | Letters sit on a CSS ring. The container `variants.visible.rotate` is 360 or -360, `repeat: Infinity`. | none |
| Animated number | `useSpring` holds the value. `useTransform` maps it through `Math.round(current).toLocaleString()`. | none |
| Text effect | `AnimatePresence` mounts `motion[as]`. `staggerChildren` is `defaultStaggerTimes[per] / speedReveal`. Item duration is `0.3 / speedSegment`. | none |
| Text loop | `setInterval(interval * 1000)` advances `currentIndex`. `AnimatePresence` swaps a `motion.div` keyed by index. | none |
| Text morph | `useId` plus per-character `layoutId`. `AnimatePresence popLayout` morphs shared letters. | none |
| Text roll | Two stacked `motion.span` faces per letter. Outgoing `rotateX` 0 to 90. Incoming 90 to 0. | none |
| Text scramble | `setInterval` every `speed * 1000` ms. Characters before `progress * length` settle. The rest pick from `characterSet`. | none |
| Accordion | `AccordionContent` mounts a `motion.div` while `value` equals `expandedValue`. `AnimatePresence` runs height and opacity. | none |
| Disclosure | `DisclosureContent` mounts a `motion.div` while `open` is true. The trigger clones the child and adds `onClick`. | none |
| Dialog | `showModal()` on a `motion.dialog`. `AnimatePresence` runs variants. `onAnimationComplete('exit')` calls native `close()`. | lucide-react `X`; vendored `usePreventScroll` |
| Morphing popover | Shared `layoutId` `popover-trigger-{id}` between trigger and content. Click outside and Escape close it. | none |
| Transition panel | `AnimatePresence mode="popLayout"` swaps a `motion.div` keyed by `activeIndex`. | `react-use-measure` 2.1.7 on the card |
| Animated background | Shared `layoutId={`background-${useId()}`}`. `AnimatePresence` mounts one overlay. Click or hover sets `activeId`. | none |
| Animated group | Container variants with `staggerChildren: 0.1`. Each child is `motion.create(asChild)`. | none |
| Border trail | CSS `offsetPath: rect(0 auto auto 0 round size)` plus `offsetDistance` 0% to 100% with `repeat: Infinity`. | none |
| Glow effect | `animate={animations[mode]}` on an absolute `motion.div`. `rotate` loops a conic gradient. | none |
| Spotlight | Parent `mousemove` writes `useSpring` `mouseX`/`mouseY`. `useTransform` offsets `left` and `top` by `size/2`. | none |
| In view | `useInView(ref, viewOptions)` swaps hidden and visible variants. `once` sets a local `isViewed` flag after the first complete. | none |
| Scroll progress | `useScroll({ container })` writes `scrollYProgress`. `useSpring` maps it to `scaleX`. | none |
| Progressive blur | Stacked `motion.div` layers. Each uses a `linear-gradient` mask and `backdrop-filter: blur(index * blurIntensity)`. | none |
| Infinite slider | Children render twice. `useMeasure` reads the track. `animate()` drives a motion value from 0 to `-contentSize / 2` with linear ease. | `react-use-measure` 2.1.7 |
| Carousel | Context holds `index`. `IntersectionObserver` counts visible items. `translateX` is `-index * (100 / visibleItemsCount)%`. | `lucide-react` 1.43.0 |
| Cursor | `document` `mousemove` writes `clientX`/`clientY` into `useMotionValue`. `useSpring` follows. `AnimatePresence` mounts the chip. | none |
| Magnetic | Distance from centre times `intensity` times falloff. `useSpring` writes `x`/`y`. | none |
| Tilt | Pointer percent to `rotateX`/`rotateY` through `useSpring` and `useMotionTemplate`. | none |
| Dock | Dock `mouseX` to item width `[40, magnification, 40]`, then `useSpring`. | none |
| Toolbar dynamic | `motion.div` animates `width` between closed and open. `useClickOutside` closes. | none |
| Toolbar expandable | `useMeasure` height plus `AnimatePresence`. Selected panel opacity follows `active`. | `react-use-measure` 2.1.7 |

## Props the docs and the source disagree on

Sliding number docs type `value` as `string`. The installed source types `value` as `number`. The stories use the source.

Spinning text docs type `children` as `ReactElement`. The installed source types `children` as `string`. The stories use the source.

Text shimmer wave docs type `as` as `string`. The installed source types `as` as `React.ElementType`. The stories use the source.

Animated number upstream examples pass `springOptions.duration` of 2000, 1000, and 10000. Motion 13.2.0 treats spring `duration` as seconds. The stories use 2, 1, and 3.
