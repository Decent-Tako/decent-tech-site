# Motion examples

Every component in this section is built to the rubric in issue 268. It has typed controls that change the animation live, a Replay or Pause control, a `play` test, the Academy brand, and an attribution block that names the animation mechanism. The build fails on a story that does not.

The default runtime is `motion` **13.2.0**. Licence MIT. Docs: https://motion.dev/docs/react . Extra packages are listed on **Runtime additions** with the reason Motion cannot do the work.

Issue 231 supplies colors, Brand Sans, and the live-text wordmark. Photographs stay in full color.

## Sources

Three sources. motion.dev and Motion Primitives were chosen by Ben on 2026-09-09. React Bits was added by issue 6 as a reference source.

## Reduced motion

`MotionConfig reducedMotion="user"` is the default. CSS animations stop under `prefers-reduced-motion`. Each Reduced motion story sets `always` and shows the final state at once.
