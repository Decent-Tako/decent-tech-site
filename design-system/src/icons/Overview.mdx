# Upstream icon resources

This section compares real icons from maintained React packages. Each cell imports the package icon. This gallery does not redraw paths and does not promote a candidate to production.

Checked on 2026-09-09 against npm, GitHub repository metadata, official docs, and the 2026-09-08 reset prior-art sheet.
